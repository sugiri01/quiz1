AI & Machine Learning Quiz

Test your knowledge of Artificial Intelligence and Machine Learning fundamentals with these 25 multiple-choice questions.
1. What is the primary goal of Machine Learning?
a) To create self-aware computers
b) To enable computers to learn from experience without explicit programming
c) To replace human programmers
d) To store large amounts of data
Correct Answer: b
2. Which of the following is NOT a type of machine learning?
a) Supervised learning
b) Unsupervised learning
c) Predictive learning
d) Reinforcement learning
Correct Answer: c
3. In supervised learning, what is a label?
a) The name of the dataset
b) The target variable or output we want to predict
c) The input features
d) The name of the algorithm
Correct Answer: b
4. What is the main purpose of the training dataset?
a) To test the model's performance
b) To store the final results
c) To teach the model patterns and relationships
d) To validate the model's architecture
Correct Answer: c
5. Which algorithm is commonly used for classification problems?
a) Linear Regression
b) Random Forest
c) K-means clustering
d) Principal Component Analysis
Correct Answer: b
6. What is overfitting?
a) When a model performs too poorly on training data
b) When a model performs well on training data but poorly on new data
c) When a model is too simple
d) When a model trains too quickly
Correct Answer: b
7. What is a neural network activation function?
a) A function that starts the training process
b) A function that introduces non-linearity to the network
c) A function that stops the training process
d) A function that loads the data
Correct Answer: b
8. What is the purpose of cross-validation?
a) To speed up model training
b) To evaluate model performance on different subsets of data
c) To create new features
d) To clean the dataset
Correct Answer: b
9. Which of these is an example of unsupervised learning?
a) Spam detection
b) Customer segmentation
c) Image classification
d) Speech recognition
Correct Answer: b
10. What is a hyperparameter?
a) A parameter learned during model training
b) A parameter set before training begins
c) A parameter that changes automatically
d) A parameter used only in deep learning
Correct Answer: b
11. What is the purpose of the test dataset?
a) To train the model
b) To evaluate the model's performance on unseen data
c) To tune hyperparameters
d) To create new features
Correct Answer: b
12. What is regularization used for?
a) To speed up training
b) To prevent overfitting
c) To create more training data
d) To visualize results
Correct Answer: b
13. What is a confusion matrix used for?
a) To measure regression performance
b) To evaluate classification model performance
c) To create new features
d) To normalize data
Correct Answer: b
14. Which of these is NOT a common activation function?
a) ReLU
b) Sigmoid
c) Quadratic
d) Tanh
Correct Answer: c
15. What is feature scaling?
a) Creating new features
b) Normalizing features to a similar range
c) Removing features
d) Combining features
Correct Answer: b
16. What is deep learning?
a) Learning that happens overnight
b) Machine learning using neural networks with many layers
c) Learning from very large datasets
d) Learning without supervision
Correct Answer: b
17. What is gradient descent used for?
a) To create new features
b) To optimize model parameters
c) To evaluate model performance
d) To clean data
Correct Answer: b
18. What is the purpose of the validation dataset?
a) To train the model
b) To tune hyperparameters
c) To make final model evaluation
d) To create new features
Correct Answer: b
19. Which metric is commonly used for regression problems?
a) Accuracy
b) Mean Squared Error
c) F1 Score
d) Precision
Correct Answer: b
20. What is transfer learning?
a) Moving data between computers
b) Using a pre-trained model for a new task
c) Transferring knowledge between team members
d) Converting data types
Correct Answer: b
21. What is bias in machine learning?
a) Personal preferences in the data
b) The model's tendency to consistently learn certain patterns
c) Political opinions in the algorithm
d) Random errors in prediction
Correct Answer: b
22. What is batch size in training?
a) The size of the entire dataset
b) The number of samples processed before model update
c) The size of the test set
d) The number of features

23. What is a decision tree?
a) An organizational chart
b) A flowchart-like structure for making predictions
c) A type of neural network
d) A database structure
Correct Answer: b
24. What is the purpose of dropout in neural networks?
a) To speed up training
b) To prevent overfitting
c) To increase model complexity
d) To clean data
Correct Answer: b
25. What is ensemble learning?
a) Learning from music data
b) Combining multiple models to improve performance
